PDF Toolkit > Универсальный инструмент для работы с PDF-документами: извлечение текста, разделение страниц, индексация и нормализация структуры

## 🚀 Возможности

### 🔍 Извлечение текста (OCR)
- Автоматическое распознавание текста с использованием OCR
- Интерактивный режим с визуальным выбором области
- Пакетная обработка нескольких PDF-файлов
- Самообучающаяся система (запоминает шаблоны для повторного использования)

### 📄 Извлечение страниц
- Извлечение первых N страниц
- Извлечение последних N страниц
- Извлечение диапазона страниц
- Поддержка одиночных файлов и пакетной обработки

### 📊 Индексация
- Сканирование метаданных PDF в SQLite
- Поиск и сохранение информации о файлах
- Умное извлечение текста по маркерам

### 🔄 Нормализация структуры
- Обнаружение и удаление дубликатов
- Организация файлов по папкам
- Создание отчетов о структуре

### 📤 Экспорт
- Экспорт данных в Excel (.xlsx)
- Экспорт в CSV
- Выбор необходимых колонок
